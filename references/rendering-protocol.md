# 科研图表重绘协议

## 目录

1. 数据映射
2. 科学完整性
3. 导出与视觉验证

## 数据映射

在 `render` 中明确声明图表类型、横纵坐标列、分组列、标签和坐标尺度。支持 `line`、`scatter`、`bar` 和 `histogram`。

- 只能按声明的列分组；
- 曲线默认保留行序；
- `segment_break` 必须拆分曲线，不能跨越缺失区连线；
- `linear` 与 `log10` 必须在提取和重绘中保持一致；
- 外部数据先规范化为独立 `data.csv`，不能覆盖原始数据文件。

## 科学完整性

- 不伪造误差条、显著性、拟合、样本量或隐藏观察；
- 没有声明规则时不删除离群值；
- 保留单位、坐标变换和数据顺序；
- 未声明系列颜色时才使用固定的色盲友好配色；
- SVG 和 PDF 中的文字应保持可编辑；
- 中文标签优先使用系统可用中文字体，并保留通用回退字体。

## 导出与视觉验证

从同一图形对象导出 PNG、SVG 和 PDF，记录文件哈希、画布尺寸、数据行数、映射关系和实际坐标尺度。

参考图比较要求像素尺寸完全一致；画布不同应报告 `canvas_mismatch`，不得缩放任一图片制造相似。画布相同时输出：

- 全画布归一化 MAE；
- 可用时的绘图区归一化 MAE；
- `residual-heatmap.png` 残差热图。

残差用于定位差异，不能单独决定科学验收结论。
