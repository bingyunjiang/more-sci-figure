# 真实图表基准框架

本目录只定义真实世界基准的收集和验收规则。当前版本没有随包附带真实图表数据，因此不得声称已经完成真实世界精度验证。

## 收录条件

每个样例必须同时具备：

1. 可合法保存和测试的来源与授权说明；
2. 原始文件 SHA-256；
3. 图表类型、页面、绘图区和坐标锚点；
4. 不参与算法调参的人工标注真值；
5. 至少两名复核者或一份明确的复核责任记录；
6. 遮挡、粘连、图例污染和不可恢复区域的标注；
7. 允许公开、仅限内部或不可分发的许可等级。

## 指标

不同图表类型分别报告：

- 曲线：数据坐标误差、覆盖率、最大缺口、误连段数量；
- 散点：中心误差、漏检、误检、粘连拒绝率；
- 柱图：柱顶误差、基线误差、漏检、误检；
- 通用：来源完整性、候选复核一致率、正式数据可追溯率。

不得只报告整体图像 MAE，也不得把白色背景占比高导致的低残差解释为数据准确。

## 合成夹具边界

`scripts/tests/` 中的合成图只用于功能和回归测试。它们不能替代带真实压缩、字体、图例、扫描噪声和复杂布局的真实样例。
